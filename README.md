# CHALANA
# MVP: The Chalana Suite is a software program that helps small businesses track invoices, manage inventory, assess operational costs, and assign invoices and employees to work orders. Chalana aims to make paper-based organization systems more efficient by keeping all components of a work order assigned to specific clients, improving customer satisfaction, and speeding up job workflow. Businesses will be able to analyze what consistently works for them and what aspects of their business help maximize profits 
# Invoices: name/address, number, total cost, edit, assign to work order, status
# Work Orders: name/address, assign employee, tool list, view/edit, budget 
# Tools: name, location, quantity available, job type association
# Profile: operational costs, monthly summary, list job types, single-user, manage employee profiles
